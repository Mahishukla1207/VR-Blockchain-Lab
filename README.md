# 🔗 VR Blockchain Lab

An immersive Virtual Reality learning experience developed in Unity to make complex blockchain concepts easier to understand through interactive visualization and simulation.

Instead of learning blockchain only through traditional text, diagrams, or videos, the VR Blockchain Lab allows users to experience and interact with blockchain concepts inside an immersive virtual environment.

The project explores how Virtual Reality can be used as an educational tool to simplify abstract technical concepts through spatial visualization and interaction.

---

## 🎯 Project Objective

Blockchain concepts such as centralized systems, distributed ledgers, decentralization, consensus mechanisms, Proof of Work, and Proof of Stake can be difficult to understand through traditional learning methods.

The objective of the VR Blockchain Lab is to create an interactive learning environment where users can explore these concepts visually and understand how blockchain systems work through immersive VR experiences.

---

## 🥽 Module 1: Centralized Systems & Distributed Ledgers

The first module introduces users to the fundamental differences between centralized and decentralized systems.

Users enter an immersive VR environment where blockchain concepts are represented using interactive objects, nodes, data flow, and visual simulations.

### Concepts Covered

- Centralized systems
- Limitations of centralized architectures
- Single points of failure
- Decentralized networks
- Distributed ledgers
- Data distribution between network nodes
- Introduction to blockchain architecture

## 🧩 Project Structure

The project currently focuses on the first learning module of the VR Blockchain Lab.

### Module 1 — Blockchain Fundamentals

**Centralized World**

Introduces users to centralized systems and demonstrates how information flows through a central server.

**Distributed Ledger**

Demonstrates how information can be shared and maintained across multiple nodes in a decentralized network.

**Interactive Learning**

Users interact with virtual objects, buttons, network components, and visual simulations to understand blockchain concepts.
